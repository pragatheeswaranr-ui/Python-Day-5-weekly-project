
# Employee Data Analysis

## Project Description

This project analyses IBM HR employee data using Python.
The project includes different visualisations to understand employee information.

## Libraries Used

- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- Nbconvert

## Installation

Install the required libraries using:

```bash
pip install -r requirements.txt
```

## How to Run

1. Open the project folder.
2. Install the required libraries.
3. Open the Jupyter Notebook.
4. Run all cells.
5. View the generated charts.

## Visualisations

1. Bar Chart
2. Histogram
3. Scatter Plot
4. Line Chart
5. Box Plot

## Report

The exported HTML report is available in the reports folder.
