Day 5 – Employee Data Analysis
Project Overview

This project focuses on employee data cleaning and exploratory data analysis using Python.

Tasks
Task 1: Data Cleaning and Exploratory Data Analysis
Task 2: Report and Presentation
Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook
Requirements

Install the required libraries using:

bash
pip install -r task2/requirements.txt

How to Run the Project
Clone the repository.
Open the project folder in VS Code.
Install the required libraries.
Open the Jupyter Notebook inside task1/notebooks/.
Run the notebook cells one by one.
View the generated HTML report inside task2/report/.

Cleaned employee dataset
