Employee Data Analysis
Project Overview

This project focuses on cleaning and exploring employee data using Python.

The main objective is to understand employee information and identify patterns related to employee attrition.

Dataset
Dataset: IBM HR Employee Attrition Dataset
Total Records: 1470
Total Columns: 35
Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
VS Code
Task 1: Data Cleaning

The following cleaning activities were performed:

Checked missing values.
Checked duplicate records.
Verified data types.
Standardised categorical text values.
Detected outliers using the IQR method.
Created a before and after cleaning summary.
Saved the cleaned dataset as clean_data.csv.
Task 2: Exploratory Data Analysis

The following analysis was performed:

Employee Attrition Analysis
Department-wise Attrition
Age Distribution
Monthly Income Analysis
Overtime Analysis
Correlation Heatmap
Project Files
dataset: Original employee dataset.
notebooks: Python analysis notebooks.
output: Cleaned dataset and analysis results.
documentation: Data cleaning decisions.
Conclusion

This project helped to understand the process of data cleaning and exploratory data analysis using Python.

It also helped identify employee characteristics and explore patterns related to employee attrition.
